## 2. Python 설치

### 2.1 다운로드

1. [https://www.python.org/downloads/](https://www.python.org/downloads/) 접속
2. 상단의 **"Download Python 3.x.x"** 버튼 클릭

> 📸 *아래와 같이 노란색 다운로드 버튼이 보이면 클릭*
> ```
> ┌─────────────────────────────────────────┐
> │  Download Python 3.13.x                 │
> │  [████ Download Python 3.13.x ████]     │
> └─────────────────────────────────────────┘
> ```

### 2.2 설치

1. 다운로드된 설치 파일(`python-3.x.x-amd64.exe`) 실행
2. ⚠️ **반드시 "Add python.exe to PATH" 체크박스 선택** (가장 중요!)
3. **"Install Now"** 클릭

> 📸 *설치 화면 하단의 체크박스 위치*
> ```
> ┌─────────────────────────────────────────┐
> │  Install Python 3.13.x                  │
> │                                         │
> │  [Install Now]                          │
> │  [Customize installation]               │
> │                                         │
> │  ☑ Use admin privileges                 │
> │  ☑ Add python.exe to PATH  ← ⚠️ 필수!  │
> └─────────────────────────────────────────┘
> ```

### 2.3 설치 확인

- Windows 검색창에 **"cmd"** 입력 → **명령 프롬프트** 실행
- 아래 명령어 입력 후 버전 번호가 출력되면 성공:

```bash
python --version
```

- 정상 출력 예시:
```
Python 3.13.3
```

> ❌ `'python'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램...` 오류 발생 시
> → [FAQ 9.1](#91-python-명령이-인식되지-않음) 참고

## 3. VS Code 및 Google Antigravity 설치

### 3.1 VS Code 다운로드 및 설치

1. [https://code.visualstudio.com/](https://code.visualstudio.com/) 접속
2. **"Download for Windows"** 클릭 → 설치 파일 실행
3. 설치 옵션에서 아래 항목 체크 권장:
   - ☑ `Add "Open with Code" action to Windows Explorer file context menu`
   - ☑ `Add to PATH`

### 3.2 필수 확장(Extension) 설치

- VS Code 실행 → 좌측 사이드바에서 **확장(Extensions)** 아이콘 클릭 (또는 `Ctrl+Shift+X`)
- 아래 확장을 검색하여 **Install** 클릭

| 확장명 | 설명 | 필수 여부 |
|--------|------|----------|
| **Python** (Microsoft) | Python 코드 실행 및 디버깅 | ✅ 필수 |
| **Korean Language Pack** | VS Code 한글 메뉴 | ✅ 필수 |
| **Jupyter** | 노트북 실행 (선택) | 선택 |
| **Markdown Preview Enhanced** | 보고서 미리보기 | 권장 |

### 3.3 Python 인터프리터 선택

1. VS Code에서 아무 `.py` 파일 열기
2. 하단 상태 표시줄에서 **Python 버전** 클릭
3. 설치된 Python 3.x 버전 선택

### 3.4 Google Antigravity 에이전트 설정 🚀

본 수업에서는 기존의 단순 챗봇 형태의 AI 어시스턴트(예: GitHub Copilot, Gemini Code Assist 등)를 넘어, **작업을 스스로 계획하고 터미널 명령과 파일 수정까지 직접 수행할 수 있는 "Google Antigravity" 에이전트**를 실습 도구로 적극 활용합니다.

- **설치 절차**:
  1. 수업 시간에 제공되는 Antigravity 안내 링크 또는 설치 패키지를 다운로드하여 설치합니다.
  2. 설치가 완료되면 독립된 애플리케이션으로 실행되거나 시스템 백그라운드에 연동되어 동작합니다.
  3. 에이전트 인터페이스(브라우저 또는 전용 UI)에서 권한을 부여받은 Google Workspace 계정으로 로그인합니다.
  4. 설정(Settings)에서 작업 디렉토리 권한을 실습 폴더(`biomaterial-handling` 등)로 지정합니다.

- **활용 예시 (Agentic Coding)**:
  - 단순 코드 완성을 넘어서, Antigravity에게 다음과 같은 복합적 지시를 내릴 수 있습니다:
    - *"12주차 실습 코드인 step1_spectroscopy.py에서 PCA 분석 부분을 추가하고, 관련 패키지를 설치한 다음 결과를 그래프로 보여줘."*
    - *"README.md 파일의 포맷팅을 수정하고, 현재 폴더의 파일 구조를 스캔해서 인덱스를 업데이트 해."*
  - 에이전트가 직접 터미널을 제어하거나 다수의 파일을 수정할 수 있으므로, 제안된 작업을 실행하기 전 항상 **승인(Approve)**을 확인해야 합니다.

## 7. 실습 코드 실행

### 7.1 기본 실행 방법

1. VS Code에서 해당 주차 폴더 열기 (예: `ko/week13/`)

## 9. 자주 묻는 질문 (FAQ)

### 9.1 Python 명령이 인식되지 않음

- **원인**: 설치 시 `Add python.exe to PATH` 미체크
- **해결**: Python 설치 파일 다시 실행 → "Modify" → 환경 변수 체크

### 9.2 pip install 오류

- **해결**: `python -m pip install 패키지명` 으로 실행하거나 VS Code를 관리자 권한으로 실행

### 9.3 한글 깨짐 문제

- **원인**: Matplotlib에서 기본 영문 폰트 사용 시 발생
- **해결**: 모든 실습 코드 상단에는 아래와 같은 설정이 포함되어 있습니다. (임의 삭제 금지)
```python
import matplotlib.pyplot as plt
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False
```
